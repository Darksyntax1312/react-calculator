# 🧮 React Calculator

A sleek, modern, and fully functional calculator built with **React**. Perform basic and advanced arithmetic operations with a clean, responsive UI that works beautifully on desktop and mobile.

## ✨ Features

- ➕ **Basic Operations** — Addition, subtraction, multiplication, and division
- 🔢 **Decimal Support** — Handle floating-point numbers with ease
- 🧹 **Clear & Delete** — Reset the display or remove the last entry
- ⚡ **Real-Time Evaluation** — Instant results as you compute
- 📱 **Fully Responsive** — Looks great on phones, tablets, and desktops
- 🎨 **Clean UI** — Minimalist design with smooth button feedback

## 📦 Getting Started

### Prerequisites

Make sure you have **Node.js** (v14+) and **npm** installed.

```bash
node -v
npm -v
```

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/react-calculator.git
   cd react-calculator
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm start
   ```
   *(or `npm run dev` if you're using Vite)*

4. **Open in browser**
   ```
   http://localhost:3000
   ```

## 🎮 Usage

| Button | Action |
|--------|--------|
| `0–9` | Enter digits |
| `+ - × ÷` | Choose an operation |
| `.` | Add a decimal point |
| `=` | Evaluate the expression |
| `AC` | Clear everything |
